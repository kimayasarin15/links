# Type & Interaction MPS CD Project 4: Links
## Introducing JS & are.na API

This is my fourth project for T&I. We started the project by collecting a range of media content on a theme of our choosing on are.na. We then swapped channels with other people in the class. 

My website explores the portrayal of female friendships in the media, collected by Sooim Kang. Inspired by Charlie XCX’s song, Girl so confusing ft Lorde, a public reconciliation of the two after being under the spotlight. The channel explores media that reveals female closeness as layered and contradictory, often misunderstood or flattened by culture. This website argues that female friendships are profoundly complex and hold a great deal of emotional depth.

I took inspiration from Charlie's album 'brat,' with it's almost anti-design nature with the bright green and blurry lower-case arial. My concept for this was to emulate the depth and layering of female friendships within my website, where you are met with a chaotic set of blocks, randomly placed, rotated and inverting, hiding the real meaning of them below. On the other side, by the pressing the button, it clears up the grid, revealing the content of the blocks. I wanted the relationship with the user to feel very interactive and exploratory. 

For responsiveness, I wanted to keep both the chaotic and grid-like vibe across all breakpoints. I reduced the grid size and on mobile, it goes to a single column, so the block content is highlighted. The modals take up more space in mobile.

We stared learning basic javascript as well as how to use are.na's API to load the content onto the page. I learnt how to use modals to open content, buttons to change states as well as changing behaviour on scrolling. 

Overall I really enjoyed this project. Not only did I resonate with the channel theme, it pushed me to move away from my design comforts so design something more playful, explorative and interactive.
