# Type & Interaction MPS CD Project 4: Links
## Introducing JS & are.na API

This is my fourth project for T&I. We started the project by collecting a range of media content on a theme of our choosing on are.na. We then swapped channels with other people in the class. 
I got Sooim's channel, exploring female friendships in the media, inspired by Charlie XCX's song, Girl, so confusing ft lorde.

I took inspiration from Charlie's album 'brat,' with it's almost anti-design nature with the bright green and blurry lower-case arial. I want the blocks to feel interactive, some with modals, some with hover so the user can feel like they are exploring each piece differently.
Female friendships are much more complicated than they are portrayed, holding emotional depth. I wanted this to come through with the interactivity and layering. 

We stared learning basic javascript as well as how to use are.na's API to load the content onto the page.
